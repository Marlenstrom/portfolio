Native Woodland Trust

Android app

UI design · UX design · Design system

Overview

Native Woodland Trust is a foundation that protects Ireland's last ancient woodlands. They bring back the original nature by planting native seeds.

They want to renew their profile and design an app.

Project brief

The foundation looks after a few different wooded areas that are open to the public. They want an app containing:

  • A way to scan a tree and find out more about it
  • A page that presents areas in the forest
  • A presentation of different hikes you can choose

The redesign of the profile is presented as a separate project.

Roles
  • User Experience (UX) Designer
  • User Interface (UI) Designer
  • Moderator in user test
Deliverables
  • Low-fidelity wireframes
  • High-fidelity mockups and prototypes
  • Usability test and findings
  • Presentation
  • Design system
  • Specification
Duration
  • 5 weeks
Tools
  • Figma, Photoshop

Design system

The Native Woodland Trust design system makes sure all their products are consistent and give the user a safe and good experience.

It defines guidelines for icons, colour, buttons, logo and typography.

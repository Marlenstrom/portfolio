Tasks and recommendations

One place to find and act on HR and health and safety tasks.

2026 · Product design · Front-end

HR and health and safety tasks were spread across several tools. I designed and built a shared overview to help users see what needs attention and take the next step.

Role
  • Lead product designer: concept, UX/UI and code
Delivered
  • Concepts and prototypes
  • Requirements document with user stories and rules
  • Built in code and sent to developers for review
Status
  • Requirements document in review

The problem

Users had to check several tools to find their tasks. The challenge was to bring these together, make urgent work easy to spot, and distinguish personal responsibilities from suggestions for the organisation.

How I started

I reviewed existing tasks and explored concepts for different roles and working situations—from a manager checking their phone between meetings to an HR specialist working through a longer list.

Tasks and recommendations

The solution combines a focused overview on the home page with a complete task list. Users can handle simple approvals directly and open the relevant tool for more complex work.

Tasks are work the user is responsible for. Recommendations suggest useful next steps for the organisation. Showing them separately makes that distinction clear.

The rules behind the interface

I defined how existing roles, line management responsibilities and direct assignments determine which tasks users see. I also specified deadlines, sorting and completion, and how the overview depends on information from each tool.

I documented these rules, user stories and open questions in a product requirements document (PRD).

From design to code

I used prototypes and the PRD to discuss the solution with the design and development team and clarify unresolved questions.

I built the solution using Claude Code, created a pull request and ran Harness checks before handing it over for developer review.
